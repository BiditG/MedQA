## Concept in Simple Words

Series completion is a reasoning pattern used in the MAT section. The scoring method is to identify the rule, test it on the full question, eliminate look-alike options, and avoid spending too long on one item. ## Why This Topic Matters in CEE

Series completion is valuable because MAT marks are usually faster than science marks when the pattern is familiar. Repeated practice builds speed and protects rank. ## Must Remember Points

- The key is relationship recognition, not memorization.
- Convert words into structure: pair relation, code shift, family tree, direction map, or statement logic.
- Do not use outside knowledge in statement-based reasoning unless the question demands common facts.
- Relationship must match exactly, not just topic.
- Check every letter in coding-decoding.
- Rough diagrams save time in relation and direction questions.
- In statements, accept given information as true.
- Write differences above the series quickly.
- For letter series, convert letters to positions when needed.

## Diagram in Words

Series completion question -> observe one feature -> form rule -> test all terms/figures -> eliminate traps -> mark only after verification.

| Focus | What to revise | Note |

| Coding | Check letter shift, reverse order, position value, alternate letters |  |
| Blood relation | Draw family tree; do not assume gender |  |
| Direction | Draw compass and trace turns from the person’s facing direction |  |
| First check | Common difference or alphabet shift. |  |
| Second check | Multiplication/division, square, cube, prime. |  |
| Third check | Alternate terms or difference of differences. |  |
| Verification | Rule must fit every visible term. |  |

## CEE Traps

- Forcing arithmetic pattern when multiplication is present.
- Ignoring reverse alphabet positions.
- Not verifying all terms.

## Common Mistakes

- Overthinking a simple Series completion pattern.
- Not drawing rough diagrams where needed.
- Guessing before eliminating options.
